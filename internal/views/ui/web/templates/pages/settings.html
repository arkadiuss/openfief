Market-data sources

Each instrument's prices, each currency's exchange rate and each index reading come from one source (D-94). When one first needs a value, it takes the highest-ranked source below that has one, and keeps it: changing the order revalues nothing and only applies to what first needs a value afterwards. A day without a value takes the latest earlier one from the same source, never another source's; the other sources' values are kept to cross-check it. By default the first-party connector ranks first: EODHD for prices, NBP for exchange rates and the treasury bond connector for CPI and the NBP reference rate.
