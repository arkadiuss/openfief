Upload statement

A statement file this account's institution exported, up to 64 MiB, such as an IBKR Flex Query statement. The core hands it to {{.Instance}}, the connector bound to this account, which decides whether it can read it; a statement of several linked accounts is booked into each one mapped to it. Importing the same statement again changes nothing.

{{if .Start}}

Opening seeds the account at go-live, the statement's date: one opening lot per holding, at the date and price it was bought, plus the cash balance below, and later statements add only what came after go-live. A statement of the whole history, from the first deposit, books every transaction instead. Either way the account starts once.

For an opening statement that holds no cash balance, such as an XTB export's open positions: the account's cash on the statement's date, in the account's currency, as 1250.00. You enter it once, now. Leave it empty when the statement holds the cash, as an IBKR Flex statement does.

{{else}}

The core chooses transactions: only what came after the account's go-live is added, and scheduled syncs continue it too. Override it only to seed again.

{{end}}
