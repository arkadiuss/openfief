Given a core with its latest valued day 2026-03-31, when the owner follows the value card's time-weighted return of this year, or the Ask box's period card for this year, the last 12 months, last year, 2025, November 2025 or two days, then the chart opens on its Performance tab with the charts' start set to the period's opening close (this year: the last valued day on or before 2025-12-31; November 2025: 2025-10-31), where the index is 100, and its last index over 100 is the card's return to the two places the card shows; and a start the owner types by hand stays as typed, 100 on that day's close.
