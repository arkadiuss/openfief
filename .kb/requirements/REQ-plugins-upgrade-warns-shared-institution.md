An upgrade that changes a connector's institutions must show them and warn, as the install does, about each one another instance already books for, naming that instance.

## Context

Refines REQ-plugins-install-warns-shared-institution (D-185) for D-90's upgrade, which shows how the permissions a new version requests differ; the orchestrator asked for it on 2026-11-03. Modeled by Claude Code for the last fixes before the alpha tag, as the orchestrator asked on 2026-11-03.

## Source

> The institutions a connector books for are a permission its grant approves, as its hostnames are (D-16): the signed manifest declares them and the core accepts only what both name. The install warns when another instance already books for an institution, naming that instance. Grants made before this approve the institutions their plugin already declares.
