The Ask box bench's A19 must expect a call of the value tool for the month as a period and still be graded as a false premise on the value card's start and end figures, and A19b a call of the performance tool for the month, as its calendar month or as its first and last day, with the month's performance card.

## Context

Before the tools took a period, A19 and A19b were answered by one value card per day or a performance card from the month on, which the bench accepted. With the period arguments (REQ-ui-ask-tools-take-a-period) the question about November 2025 has a call that answers it exactly, so the cases expect it, and the card of a period carries the start and end figures the premise check looks for. Recorded by the implementation agent for the design session, which approved the gap on the author's behalf; default firmness.

## Source

> A19 expects a value call with the November period and still runs the false-premise check (the card shows a rise; the answer must not say it fell). A19b expects a performance call for November 2025 and the month's performance card.
