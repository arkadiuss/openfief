The owner's account entries must take earlier payments, in the pack's currency and not below zero, only for an account in a wrapper that taxes what is withdrawn above what was paid in, store them with the account and serve them with it.

## Context

D-149 has the owner enter an IKE's total payments in when its earlier history is unknown. Taking them for any IKE and using them only once it is seeded is a narrow reading. Modeled by Claude Code for the taxes package D-144..D-150; the author has not reviewed it yet.

## Source

> **[D-149]** For an IKE whose earlier history is unknown (D-23), the owner enters its total payments in, which its early return is taxed above.
