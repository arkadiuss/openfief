The demo dataset must enter its seeded bond IKE's earlier payments as its bonds' cost plus its opening cash, so its liquidation value is taxed above them.

## Context

D-149 has the owner enter an IKE's earlier payments when its history is unknown; the demo's bond IKE is seeded at go-live, so the demo enters them as an owner would. Modeled by Claude Code for the taxes package D-144..D-150; the author has not reviewed it yet.

## Source
