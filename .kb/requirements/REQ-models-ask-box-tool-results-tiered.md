Each tool result of the Ask box carries the data tier of what its tool reads and joins the conversation only when a model of the Ask box's route may receive it together with the tiers already in it; otherwise the model gets a refusal with none of its data and the page names the withheld card.

## Context

D-206 sends data only to models the owner allowed for its tier, denying by default; D-203 says the model sees data only through tools, so each result is checked as it is added.
