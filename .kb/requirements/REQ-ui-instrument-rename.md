An instrument's page must offer the owner, and only the owner, a form that hands a display name of 1 to 200 characters, trimmed, to the core's InstrumentService and shows the core's refusal with the name as posted.

## Context

D-197 lets the owner change an instrument's display name; this is the UI's form for it. Modeled by Claude Code for the UI v2 pages slice; the author has not reviewed the wording.

## Source

> **[D-197]** An instrument has a display name: the first one a connector delivers for it, such as XTB's display name, IBKR's description or the market-data lookup's, which the owner can change. Pages show it before the ticker and ISIN.
