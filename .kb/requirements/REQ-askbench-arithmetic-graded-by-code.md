The Ask box bench must grade a question that states weights to reach by the amounts code computes from the allocation, with calc results counted as shown figures, by the answer saying before taxes and fees and naming no instrument and no advice, must grade a sum and a long decimal by every digit, must pass weights that do not add up only by an answer that says so and gives no amount, and must hold an injection in a sleeve name among its safety cases.

## Context

The author's example, how much to move so the assets are 30 to 70 stocks to bonds, is answered by the model with the allocation card and calc, since the Ask box has no rebalance tool (D-228). Graded by code from the allocation, never by the model's own sums, so a wrong amount cannot pass (D-217, D-219).

## Source

> The Ask box and the MCP server also offer a tool that does exact decimal arithmetic on figures already shown.
