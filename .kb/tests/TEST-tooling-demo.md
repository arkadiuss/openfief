Runs scripts/demo/demo.sh against a fake hcloud that logs every call and answers with synthetic prices and inventories, and a fake curl that plays the Cloudflare DNS API on a JSON record file, so no Hetzner or Cloudflare API is called. Hetzner: plan prints each price and the gross total and creates nothing; up refuses a bigger server or a project over DEMO_BUDGET_EUR before any create call; up creates the firewall, then the server with the app and env labels, the SSH key and the rendered cloud-init, and creates nothing when both exist; the firewall allows SSH only from DEMO_SSH_CIDRS and HTTP(S) from DEMO_HTTP_CIDRS; down needs CONFIRM and deletes the server before its firewall; HETZNER_API_TOKEN stands in for HCLOUD_TOKEN; neither token appears in arguments, output or files. DNS: plan shows the changes and makes none; up creates a DNS-only A and a CAA record with the comment managed-by=openfief-demo env=demo after the server, a second up changes nothing, a new IPv4 updates the A record in place, a stale AAAA of ours is deleted, DEMO_DNS_AAAA=on adds one; records of other demos, the docs site and hand-made records are never changed; a record without the comment at the demo's name makes up refuse and down leave it; recreate keeps the records; without a Cloudflare token no DNS call is made and the machine derives its sslip.io host, and DEMO_DOMAIN=none skips DNS. demo.sh dns-docs keeps docs.<domain> a DNS-only CNAME with its own comment, refuses a foreign record there, and never touches the demo's records. SSH: without a labelled key and SSH sources, a throwaway Ed25519 public key labelled openfief-ssh=throwaway is uploaded and installed, reused later, and deleted by down; the private half never reaches disk. cloud-init pins versions and checksums per architecture and rejects malformed values. A false pass would be a fake that accepts any call: both fakes fail on unexpected arguments.
