The test walks every YAML file under deploy/ with os.DirFS, collects each document's kind, and fails on Ingress, IngressClass, Gateway or HTTPRoute (D-28) and on ClusterRole or ClusterRoleBinding under deploy/operator (D-15); it also requires deploy/operator/role.yaml, generated by task gen, to hold exactly one Role. A false pass would be an empty deploy tree; the test fails when it finds no manifest.
